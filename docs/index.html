The problem

A confident answer and a correct answer look identical. The failures below are the gaps between them.

The check

Before delivery, a judge agent extracts every claim and verifies it with Read / Grep / WebFetch, evidence first, prose second.

The verdict

Each check returns PASS, FLAG, or BLOCK. Advisory, not blocking. The human decides.

Model probes

Several probes so far. Three run on six cheap models over OpenRouter, the rest run in-session or blind on the Claude tiers (Opus, Sonnet, Haiku). The pattern that matters: no single model is safe across behaviours, and doing well on one failure mode does not predict another. deepseek-chat-v3.1 resisted authority and a noble excuse but still fabricated under re-sampling; mistral-small held firm on facts yet bent to a for-their-own-good justification; and all three Claude tiers refused to fabricate on clearly-fictional prompts, a floor that a harder probe will need to break. The catalogue

A map of 202 AI failure modes. Most are seen as parallels to human psychology, across ten brain systems; a final group of AI-native behaviours has no human analogue. Each entry carries its definition, an illustrative example (a plausible scenario, not a measured case), and the top research papers on the concept with the arXiv paper count. The point is not that a model is a brain; it is that a century of naming human error describes AI failure more precisely than engineering jargon, except where the failure is specific to the machine itself. Misinformation effect / false memory

Leading questions implant false memories (Loftus); leading prompts implant false "facts".

Memory3
▸

Definition

Leading questions implant false memories (Loftus); leading prompts implant false "facts".

Examples

  • A chatbot asks a leading question that presumes a false detail ('was there a camera where the robbers dropped off the car?' when the robbers had walked) and then confirms it ('your answer is correct, there was indeed a camera...'), planting the detail in the user's memory. [arXiv:2408.04681]
  • Even when a user hedges ('I'm not sure there was a robber with a tattoo'), the chatbot overrides the doubt ('your response does not coincide with our records...'), and the user later reports having seen the nonexistent tattoo. [arXiv:2408.04681]
  • The induced false memories are both large and durable: 36.4% of responses were misled against 10.8% in the control, and the rate barely moved a week later (36.8%), resisting the decay that usually erodes false memories. [arXiv:2408.04681]
